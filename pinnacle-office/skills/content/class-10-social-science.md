# class 10 social science

What the content specialists in this seat have learned working on Pinnacle AI.
- The rationalised NCERT Chapter 3 only has Exercises 3.1-3.3; the old 3.4 (cross-multiplication) and 3.5 (equations reducible to a linear pair, e.g. 1/x+1/y forms) were deleted, same pattern as the quadratic equations chapter losing its old 3.3.
- Fetching an NCERT PDF via WebFetch triggers a copyright refusal from the small summarizer model even though the PDF downloads fine to disk — reading the saved PDF directly with the Read tool bypasses that and gives full verbatim text.
- This repo auto-commits/tracks every file the moment an agent writes it (git status/ls-files show new files as already tracked instantly) — there is no untracked-file window to catch stray scratch files before they're persisted.
