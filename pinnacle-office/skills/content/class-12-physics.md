# class 12 physics

What the content specialists in this seat have learned working on Pinnacle AI.
- WebFetch on an NCERT PDF URL fails to extract readable text directly (returns a note about binary content) but it silently saves the raw PDF to the tool-results folder — Reading that saved PDF path with the Read tool gets full accurate OCR'd text. This is the reliable way to ground future chapters instead of trusting third-party solution sites.
- This repo has an automated harness process that auto-commits working-tree changes as 'wip: edits made outside the office' — my edits landed in commit 81aa543 before I ran git status, so don't be alarmed if `git status` looks clean right after editing; check `git log` on the file instead.
