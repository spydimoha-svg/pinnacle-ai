# npm and library research

What the supply specialists in this seat have learned working on Pinnacle AI, a CBSE tutoring web app.

- Piper: piper-plus (github.com/ayutaz/piper-plus) is the MIT-compatible fork with no espeak-ng dependency (ONNX + native + WASM builds, 38MB multilingual base model) — the original design-and-asset-sources.md note only flagged the GPL fork (piper1-gpl) without naming this fix. Piper models are single-speaker, so 5 character voices means 5 separate ~60-75MB WASM downloads — lazy-load per selected character, don't preload all. @mintplex-labs/piper-tts-web claims MIT on its npm page but re-verify which fork it vendors given the GPL-fork risk.
- Kokoro-82M (Apache-2.0, kokoro-js npm, 100% client-side WASM/WebGPU): 54 preset voices (11F/9M US English, 4F/4M British, 2F/2M Hindi), but Hindi/non-English voices are trained on thinner data per Kokoro's own README — don't assume Hindi narration matches English quality without testing it first.
- flite/flite2 npm packages are dead (13/7 years since last publish) and assume a system audio player for playback — for serverless use, invoke the compiled flite CLI directly with `-o` for wav bytes, not the npm wrapper.
- Android Chrome/Firefox cannot switch speechSynthesis voice — it silently reverts to the device default. Any "more distinct character voices" fix on mobile web needs an actual bundled TTS model (Kokoro/Piper); pitch/rate tuning on the OS voice (cast.ts's current approach) has a hard ceiling here.
- tesseract.js v7 (Apache-2.0, WASM, no system binary needed) beats poppler-utils for OCR here because poppler-utils only rasterizes PDF pages, it doesn't OCR them, and it's a system package Supply can't install anyway.
- GitHub Models (playground, catalog, inference API, BYOK) was fully retired 2026-07-30, not just gpt-4o-mini deprecated — the api/_llm.ts fix is removing the github factory entirely, not swapping model IDs.
- Groq: check console.groq.com/docs/deprecations specifically for shutdown dates — the per-model page doesn't mention deprecation at all, and deprecated models keep answering normally right up to the cutoff.
- Cerebras's free-tier catalog is volatile (collapsed ~12→2 models in one week, May 2026; llama-3.3-70b is now gone) — re-verify more often than other providers. Neither its Customer Management API nor its support FAQ (article 5041581099) exposes org type/subscription/billing programmatically, only the console UI does — and the API key itself can't be curled to determine this since it authenticates inference calls, not a browser session.
- NVIDIA NIM uses vendor-prefixed model IDs (`meta/llama-3.3-70b-instruct`), not the bare form Groq/Cerebras use — swapping to NIM means respecifying the model ID, not just the base URL. Its free credits are also an explicit "trial... for evaluation and prototyping only" per NVIDIA's own docs, disqualifying it from student-facing production.
- Cohere's trial keys are contractually barred from production/commercial use per their own docs — check for this same disqualification on any other "free trial key" provider before recommending it.
- SambaNova: chat endpoint is `api.sambanova.ai/v1/chat/completions` (confirmed). `docs.sambanova.ai/docs/en/get-started/api-keys-and-urls` now 404s — working paths are under `/docs/en/...` and `/docs/api-reference/...`. Free tier is 20 requests/DAY per model (separate from the 20 RPM cap) — round-robining SambaNova's free models only yields ~60-100 req/day total, not a real second leg.
- Cloudflare Workers AI gives 10,000 neurons/day, resetting daily — meaningfully better than NVIDIA's one-time trial pool or Cohere's 1,000-calls/month cap because it renews rather than running out for good.
- Mistral's free tier needs no credit card ("Free mode is default for new accounts" per admin docs), but actual rate-limit numbers are behind login-gated admin.mistral.ai/plateforme/limits — the "1B tokens/month" figure repeated on aggregator sites is unconfirmed on any Mistral-owned public page.
- Google no longer publishes static free-tier RPM/TPM/RPD numbers at ai.google.dev/gemini-api/docs/rate-limits — it just links to a per-account aistudio.google.com/rate-limit dashboard, so no public doc URL can prove a specific Gemini free-tier number anymore.
- OpenRouter's `GET /api/v1/models` is fully public, no key needed — the cheapest provider to health-check, zero secrets required.
- For provider health checks, poll the `/models` list endpoint, not a 1-token chat completion — list endpoints are free and don't touch the per-minute token quota students share, so the check itself can't trigger the 429s it's trying to detect.
- No `vercel plan`/`vercel billing` CLI command exists. `vercel usage` and `vercel contract` don't print the plan tier name — use `vercel api <endpoint>` against the REST API, or read the dashboard billing page directly.
- GitHub's failed-scheduled-workflow email isn't on by default — the account that commits the workflow file must opt in once at Settings → Notifications → Actions → Email → "Only notify for failed workflow runs", or the whole alerting mechanism silently fails.
- egazette.gov.in's TLS error is a server-side missing-intermediate-cert misconfig, not a self-signed/private CA (confirmed via crt.sh: the leaf is issued by the trusted Let's Encrypt YR2; browsers hide this via AIA auto-fetch, Node doesn't). Fix is supplying the missing intermediate as an extra trusted cert via `https.Agent`'s `ca` option (or `curl --cacert`) — that's proper validation, not a bypass.
- Rule 10 conflict between skills/legal/privacy-policy.md (DigiLocker-style verification required) and skills/supply/automation-and-integration.md (self-declaration equally valid) was adjudicated 2026-08-04 in favor of automation-and-integration.md — privacy-policy.md line 6 is outdated and owned by Legal, outside Supply's edit scope.
- `npm audit` requires an existing package-lock.json/npm-shrinkwrap.json — it reads that file, never generates one; no lockfile means a hard error, not silent creation. Its only filesystem side effect is npm's own advisory cache under `~/.npm`, same as `npm view`/`npm ls` already do under the existing survey grant.
- Mistral's free tier uses API inputs/outputs for model training by default — there's an opt-out in the Admin Console. That has to be flipped before any student traffic goes through this key, given the DPDP-Act sensitivity around minors' data this project already treats as a hard constraint.
- mistral-small-latest is the right default, not mistral-large-latest — it's the open-weight, cheaper-to-rate-limit model and matches the file's existing convention of defaulting to the smallest capable model with an env override for anyone who wants to swap it.
- The Experiment vs Scale plan choice happens at first API-key creation (API Keys tab -> 'Choose a plan'), not at account creation itself — someone can have an account with no plan selected yet.
- Multiple sources now agree phone verification (not a credit card) is the real gate on the free tier, on top of email/SSO signup. That's a firmer, more specific claim than my previous note ('needs no credit card') — the credit-card-free part still holds, phone verification is the added friction point.
- admin.mistral.ai/plateforme/limits is behind auth.mistral.ai (Ory Kratos-based login) with a return_to redirect — confirms this data cannot be scraped or proxied by any tool without a live authenticated session, so this really is a create-it-yourself, one-time human task.
- katex versions 0.11.0 through 0.16.20 carry five separate moderate advisories (GHSA-cg87-wmx4-v546, GHSA-3wc5-fcw2-2329, GHSA-f98w-7cxr-ff2h, GHSA-cvr6-37gx-v8wc, GHSA-64fm-8hw2-v72w) all fixed by 0.16.10 or 0.16.21 — anything below 0.16.21 needs an upgrade, anything at or above is clean.
- marked had a high-severity 3-byte-payload OOM DoS (GHSA-6v9c-7cg6-27q7) but it only affected 18.0.0-18.0.1, patched in 18.0.2 — very narrow window, easy to miss if you only check 'marked has advisories' without version-range detail.
- mermaid has five advisories all clustered in 2025-2026 (CVE-2026-41159/41150/41149/41148, CVE-2025-54881) covering CSS injection via config (fontFamily/themeCSS), classDef HTML/CSS injection in diagrams, Gantt infinite-loop DoS, and sequence-diagram-label XSS — every one of them was closed by 11.15.0, so anything below that version is exposed on multiple fronts at once, not just one.
- marked-katex-extension has zero advisories in the GitHub Advisory Database as of this check — it's a thin wrapper so that's plausible, not a gap in the search.
- dangerouslySetInnerHTML usage in this repo is limited to src/components/ui.tsx and src/components/LessonPlayer.tsx — that's the actual attack surface for any future marked/katex/mermaid XSS, worth checking those two files specifically if a new advisory ever does land.
- Cerebras's catalog has now reshuffled a third time: it's down to exactly 3 models (gpt-oss-120b Production; gemma-4-31b and zai-glm-4.7 Preview), and zai-glm-4.7 is already scheduled for deprecation 2026-08-17. gpt-oss-120b is the only non-preview model, so it's the only safe default.
- Aggregator/listicle search results (freellm.net, awesomeagents.ai, adam.holter.com) still claim Cerebras's free tier includes Llama 3.3 70B — that's stale. Only inference-docs.cerebras.ai/models/overview, fetched directly, is current.
- Gemini has TWO newer stable flash generations past 2.5: gemini-3.5-flash and gemini-3.6-flash (listed first, newest). gemini-2.5-flash still answers but is itself scheduled for shutdown 2026-10-16, so it's not a safe replacement default either — go straight to 3.6.
