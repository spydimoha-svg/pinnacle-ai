# CBSE and NCERT sources

What the supply specialists in this seat have learned working on Pinnacle AI.
- Gitleaks' only default rule that could catch an arbitrary hardcoded string is 'generic-api-key'. It requires one of these exact substrings adjacent to the assignment: access, auth, api, credential, creds, key, passwd, password, secret, token. 'PASSCODE' contains none of them, so MASTER_PASSCODE never gets scanned at all (gitleaks even keyword-prefilters lines before running any regex, for speed).
- Same rule also requires the captured secret value to be 10-150 chars (or a base64-shaped string). 'PEAK-2026' is 9 characters, so it would fail the length check even if the keyword matched.
- TruffleHog's default detector set is ~800 known third-party API key formats (AWS, Stripe, GitHub, etc.) plus verification against those services' APIs — it ships with no generic keyword/entropy detector enabled by default (that 'Generic scanner' is an opt-in feature, and even enabled it requires 16-64 char values, so 'PEAK-2026' would still be too short).
- Net effect: neither popular free secret scanner, run out of the box, will ever flag this specific bug. It's a client-side authorization flaw (a check that should happen on the server never does), not a leaked-credential-format bug — the two problems look similar but need different tooling. A scanner is the wrong primary defense here regardless of ruleset tuning.

- NTA's copyright policy (exams.nta.nic.in/copyright-policy/) allows free reproduction of NTA material but only 'after taking proper permission from National Testing Agency' — the papers are free to download for a student today, but bulk redistribution inside a product needs an actual permission request sent to NTA first, this is a process step not a blocker.
- Google's live deprecations table (ai.google.dev/gemini-api/docs/deprecations.md.txt) is the only place that states the *official* replacement per model — the human-readable model page sometimes names a different, shorter-lived one. Always check the raw table, not just the prose page, before recommending a Gemini replacement.
- GROQ_FALLBACK_MODELS' default second entry (llama-3.1-8b-instant) is on the identical 2026-08-16 kill date as the primary model — Groq's own deprecation notice covers both models in one announcement. Any fix to DEFAULT_MODEL.groq that ignores the fallback list still breaks on 08-16.
- Cerebras' llama-3.3-70b didn't just quietly age out — WebSearch corroboration found it was deprecated on a specific prior date, 2026-02-16, which is consistent with it already being absent from the live catalog fetched today.

Do not spend more than one retry on this; it will not resolve itself.
- typescript is already a devDependency (5.9.3) with a working local binary at node_modules/.bin/tsc — no procurement, install command, or network fetch is needed for anyone who does get a working interactive Bash session to run this check.

- GROQ_FALLBACK_MODELS already defaults to 'openai/gpt-oss-120b,llama-3.1-8b-instant' (api/_llm.ts line 128), so gpt-oss-120b is already live in the fallback chain today, not a new addition. - dpdpa.com/dpdparules/rule10.html mirrors the final notified rule text verbatim (three routes: (a) reliable details already held, (b)(i) voluntarily provided by the individual, (b)(ii) virtual token from an authorised entity) but carries no visible notification date on the page itself, so it should never be cited alone as proof of 'final not draft' — pair it with a dated secondary source.
- scconline.com/blog/post/2025/11/14/meity-notified-digital-personal-data-protection-rules-2025/ is a clean, dated (14 Nov 2025), non-paywalled corroboration that explicitly labels itself as covering the notified rules and names self-declaration as one of the three valid Rule 10 routes — good default citation for this specific contradiction going forward.
- Rules 3, 5-16, 22 and 23 (which includes Rule 10) only come into force 18 months after the 13 Nov 2025 gazette publication, i.e. around May 2027 — the entire verifiable-parental-consent obligation is not yet legally in force. This wasn't in scope to resolve but materially affects how urgently Legal should treat either reading of Rule 10 today.
