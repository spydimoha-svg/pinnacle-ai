# Where these faces came from

Twenty four photographs from Unsplash, plus `pinnacle.jpg`, which is a copy of
`11.jpg`.

The Unsplash licence grants free use, commercial and non commercial, with no
permission and no attribution required. `sources.txt` records the exact photo
id behind each file so any one of them can be traced back.

They are stored here rather than hotlinked so the office still works with the
network off, and so nothing about who works here depends on somebody else's CDN
staying up.

## What is deliberately not here

The creator photographs on neocultural-couture.webflow.io. That site credits
each of them to a named artist. They are those artists' work, not ours, and
putting them inside Pinnacle would be putting somebody else's copyright inside
Ayaan's product.

The reference is for how the page is built and lit. It is not a source of
pictures.
